Kết nối GitHub

Token Discord vẫn nằm trong Secrets của repo. Đừng nhập nó vào trang này. Ở đây chỉ cần một token GitHub quyền hẹp.

  1. Mở trang tạo fine-grained token.
  2. Đặt tên tùy ý và chọn thời hạn, ví dụ 90 ngày.
  3. Repository access: chọn Only select repositories, rồi chọn repo Online-Forever.
  4. Repository permissions: đặt Actions thành Read and write. Muốn dùng ô cập nhật token Discord bên dưới thì thêm Secrets: Read and write. Không cấp quyền nào khác.
  5. Bấm Generate token và dán vào ô bên dưới.

Token chỉ được lưu trong trình duyệt của bạn và chỉ gửi tới api.github.com.

Cập nhật token Discord

Dán token Discord mới vào đây để lưu thành Secret TOKEN của repo. Token được mã hóa ngay trong trình duyệt rồi gửi thẳng tới GitHub. Trang không lưu nó, và ô sẽ tự xóa sau khi lưu.

Cần thêm quyền Secrets: Read and write cho token GitHub.
